# Rudra Round 2 — C Debugging

## Problem

You are given a small C program that processes sensor readings from a robot.

Your task is to fix the project so that it compiles and produces the expected output.

### Expected output

Readings: 12 7 18 5 20
Maximum: 20
Minimum: 5
Sum: 62
Even readings: 12 18 20

### Rules

- Do not rewrite the project from scratch.
- Find and fix the existing problems.
- There may be more than one problem.
- You are not told how many problems exist.
- You may edit the source files.
- Make sure the final program compiles and produces exactly the expected output.

### Build

From the round-2 directory:

gcc main.c sensor.c stats.c -o rudra2

Windows PowerShell:

.\rudra2.exe

Good luck.
